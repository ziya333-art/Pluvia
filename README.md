# Pluvia

A weather app with rooms, skies, and a voice of its own — forked from
[Bura](https://github.com/davidtakac/bura) by David Takač, GPLv3 like its parent.

Pluvia keeps everything Bura stands for — Open-Meteo data, no accounts,
no tracking, no location access — and gives it a new architecture of navigation.

## What's different

- **Every box a door** — each tile on the summary opens its own metric room
- **The sky in every screen** — weather-image backdrops under glass
- **Daily Summary** — a briefing panel below every chart
- **Modern charts** — monotone cubic curves, gradient strokes, drag-to-scrub on all five metrics
- **The pressure instrument** — a 270° tick gauge on the front tile
- **Matched rows** — paired tiles stretch to equal heights
